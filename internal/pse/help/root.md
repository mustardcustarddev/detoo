Command-line tools for working with a log of decisions made with PIOSEE:
Problem, Information, Options, Select, Execute, Evaluate.

PIOSEE records are stored as Markdown files in a subdirectory of the project,
by default `docs/piosee`.  Each record's file name begins with `piosee-` and
its number, such as `piosee-0001-make-decisions-with-piosee.md`.  Run
"pse init" to start a log, and "pse new" to add to it.
