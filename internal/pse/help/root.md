Command-line tools for working with a log of PIOSEE playbooks.  Each playbook
plans for a situation before it arises: the Scenario, the Problem to decide,
the Information to gather, the Options, how to make the Selection, the steps
of Execution, and the Evaluation of the result.

PIOSEE playbooks are stored as Markdown files in a subdirectory of the
project, by default `docs/piosee`.  Each playbook's file name begins with
`PIOSEE-` and its number, such as
`PIOSEE-0001-plan-for-incidents-with-piosee.md`.  Run "pse init" to start a
log, and "pse new" to add to it.
