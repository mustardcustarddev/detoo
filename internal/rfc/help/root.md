Command-line tools for working with a log of requests for comments (RFCs).

RFCs are stored as Markdown files in a subdirectory of the project, by default
`docs/rfc`.  Each RFC's file name begins with `RFC-` and its number, such as
`RFC-0001-use-requests-for-comments.md`.  Run "rfc init" to start a log, and
"rfc new" to add to it.
