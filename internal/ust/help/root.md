Command-line tools for working with a log of user stories.

User stories are stored as Markdown files in a subdirectory of the project, by
default `docs/userstory`.  Each story's file name begins with `STORY-` and its
number, such as `STORY-0001-describe-work-in-user-stories.md`.  Run "ust init"
to start a log, and "ust new" to add to it.
