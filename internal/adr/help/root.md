Command-line tools for working with a log of architecture decision records.

Decision records are stored as Markdown files in a subdirectory of the
project, by default `docs/adr`.  Each record's file name begins with `ADR-`
and its number, such as `ADR-0001-record-architecture-decisions.md`.  Run
"adr init" to start a log, and "adr new" to add to it.
