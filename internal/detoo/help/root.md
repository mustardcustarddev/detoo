Looks after a project's logs as a whole, the logs that adr, rfc, ust, plm and
sop keep, and installs the agent skills that drive those tools.

Run "detoo doctor" to check that each log is where its tool looks for it, and
named and numbered as its tool names documents today, and "detoo doctor --fix"
to put it right.

Run "detoo skills install" to install the agent skills, which write ADRs, RFCs,
user stories, playbooks and SOPs with the tools, "detoo skills update" to
bring them up to date, and "detoo skills remove" to remove them.
