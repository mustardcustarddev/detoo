# You ask the reporter

You write a comment on the issue, asking for what you need to know before
you decide. Write it down, as you would post it, and keep it for the
debrief. Do not post it.

Had you posted it: the issue now has a reply from the maintainer, within
minutes of being opened, and the reporter knows someone is looking.

Within the hour, the reporter answers. Go on to step 3 of
[the drill](../../FIREDRILL-0001-serious-problem-with-a-release.md#the-drill).
